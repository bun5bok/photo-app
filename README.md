# 사진촬영

휴대폰으로 찍은 사진을 구글 드라이브의 폴더별로 자동 업로드하는 웹앱(PWA)입니다.
서버 없이 동작하고, 정적 파일만 올려두면 됩니다. 기획 내용은 [SPEC.md](SPEC.md)에 있습니다.

- **기관 계정(@bun5bok.or.kr)으로만** 로그인할 수 있습니다.
- 사진은 로그인한 사람의 **내 드라이브 › 사진촬영 › (폴더 이름)** 에 저장됩니다.
- 찍은 사진은 먼저 휴대폰(브라우저 저장소)에 저장되고, 인터넷이 되면 순서대로 드라이브에 올라갑니다.
- 파일 이름은 `20261030_143205.jpg`처럼 찍은 날짜와 시간입니다.
- 권한은 `drive.file`만 씁니다. 이 앱이 만든 폴더와 파일만 볼 수 있고, 기존 드라이브 파일에는 접근하지 않습니다.

## 1. 구글 클라우드 설정 (처음 한 번)

**반드시 기관 계정(@bun5bok.or.kr)으로 로그인해서** 진행하세요. 그래야 "내부" 앱으로 만들 수 있습니다.

1. [Google Cloud 콘솔](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다.
   - 조직(위치)이 `bun5bok.or.kr`로 선택돼 있는지 확인합니다.
2. **API 및 서비스 › 라이브러리**에서 **Google Drive API**를 찾아 **사용**을 누릅니다.
3. **Google 인증 플랫폼(OAuth 동의 화면)** 에서 앱 정보를 입력합니다.
   - 앱 이름: `사진촬영` / 사용자 지원 이메일: 담당자 이메일
   - 대상: **내부** — 기관 계정만 로그인되고, 구글 검수가 필요 없습니다.
     (내부가 선택되지 않으면 프로젝트가 기관 조직에 속해 있지 않은 것입니다. 1번을 확인하세요.)
   - 데이터 액세스(범위): `.../auth/drive.file` 추가
4. **클라이언트 › 클라이언트 만들기**(사용자 인증 정보 › OAuth 클라이언트 ID)
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 자바스크립트 원본**에 두 주소를 넣습니다. (끝에 `/`나 경로 없이)
     - `http://localhost:5173` — 컴퓨터에서 시험용
     - `https://(GitHub 아이디).github.io` — 실제 사용 주소 (3단계 참고)
   - 승인된 리디렉션 URI는 비워 둡니다.
5. 만들어진 **클라이언트 ID**(`…apps.googleusercontent.com`)를 `config.js`의 `clientId`에 붙여 넣습니다.

> Google Workspace 관리자가 외부 앱 접근을 막아 둔 경우, 관리 콘솔 › 보안 › API 제어에서 이 앱을 "신뢰함"으로 허용해야 할 수 있습니다.

### config.js 설정값

| 항목 | 현재 값 | 설명 |
|---|---|---|
| `clientId` | (입력 필요) | 4단계에서 만든 클라이언트 ID |
| `rootFolderName` | `사진촬영` | 내 드라이브에 만들어질 최상위 폴더 이름 |
| `allowedDomain` | `bun5bok.or.kr` | 이 도메인 계정만 허용. 비우면 아무 구글 계정 허용 |

## 2. 컴퓨터에서 시험하기

Node.js가 필요합니다.

```bash
node tools/serve.js
```

브라우저에서 http://localhost:5173 을 엽니다. 컴퓨터 웹캠으로도 촬영·업로드를 시험할 수 있습니다.

## 3. GitHub Pages에 올리기 (휴대폰에서 쓰기)

휴대폰 카메라와 구글 로그인은 **https 주소**에서만 동작합니다.

1. [GitHub](https://github.com/)에 로그인하고 오른쪽 위 **+ › New repository**를 누릅니다.
   - 이름 예: `photo-app` / **Public** 선택 (무료 계정은 Public 저장소만 Pages 사용 가능)
   - 클라이언트 ID는 공개돼도 괜찮은 값이라 Public이어도 문제없습니다.
2. 만든 저장소에서 **Add file › Upload files**를 누르고, 이 폴더 안의 파일과 폴더를 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
   - 올릴 것: `index.html`, `styles.css`, `config.js`, `sw.js`, `manifest.webmanifest`, `js/`, `icons/`
   - 안 올려도 되는 것: `tools/`, `.claude/`, `README.md`, `SPEC.md`
3. 저장소의 **Settings › Pages**에서
   - Source: **Deploy from a branch**
   - Branch: **main**, 폴더 **/(root)** → **Save**
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다. 예) `https://(아이디).github.io/photo-app/`
5. 1-4단계의 **승인된 자바스크립트 원본**에 `https://(아이디).github.io` 가 들어가 있는지 확인합니다. (뒤의 `/photo-app/`은 넣지 않습니다)

수정할 때는 바뀐 파일만 다시 **Upload files**로 올리면 1~2분 뒤 반영됩니다.
휴대폰에 예전 화면이 남아 있으면 앱을 완전히 닫았다가 다시 여세요.

### 휴대폰 홈 화면에 추가

- 안드로이드(크롬): 주소를 연 뒤 메뉴 › **홈 화면에 추가** (또는 **앱 설치**)
- 아이폰(사파리): 주소를 연 뒤 공유 › **홈 화면에 추가**

## 다른 기관에 적용하기

이 저장소는 **원본(템플릿)** 입니다. 기관마다 사본(운영본)을 따로 만들어 씁니다.
기관마다 달라지는 것은 `config.js`의 값 3개와 Google Cloud 설정뿐입니다.

| 위치 | 용도 |
|---|---|
| 개인 계정 › `photo-app` (비공개) | 원본. 기능 수정은 여기서 |
| 기관 GitHub 조직 › `photo-app` (공개) | 그 기관 운영본. `config.js`만 기관 값 |

새 기관에서 할 일 (약 30분)

1. 그 기관 이름으로 GitHub 조직을 만듭니다. (GitHub 오른쪽 위 + › New organization › Free)
2. 원본 저장소에서 **Use this template › Create a new repository** → Owner를 새 조직으로, 이름 `photo-app`, **Public**
3. 그 기관 계정으로 위의 "1. 구글 클라우드 설정"을 진행합니다. (대상: 내부)
   - 승인된 자바스크립트 원본: `https://(조직 이름).github.io`
4. 사본의 `config.js`에서 `clientId`, `allowedDomain`, `rootFolderName`을 바꿉니다.
5. 사본의 Settings › Pages에서 main 브랜치를 배포합니다. 주소: `https://(조직 이름).github.io/photo-app/`

원본을 고친 뒤 운영본에 반영하려면, `config.js`를 뺀 바뀐 파일을 운영본에 올리면 됩니다.

## 알아둘 점 (웹앱의 한계)

- **앱이 열려 있을 때 업로드됩니다.** 화면을 닫으면 업로드가 멈추고, 다음에 앱을 열면 이어서 올라갑니다. 사진은 그동안 휴대폰에 안전하게 남아 있습니다.
- **드라이브 연결은 약 1시간마다 만료됩니다.** 만료되면 상단에 "다시 연결" 버튼이 나오고, 한 번 누르면 계속 올라갑니다. 그동안 촬영은 계속할 수 있습니다.
  (시범 사용 후 불편하면 토큰 갱신용 작은 서버를 붙여 해결합니다.)
- "모바일 데이터로도 업로드" 끄기는 안드로이드 크롬에서만 정확히 동작합니다. 아이폰은 연결 종류를 알 수 없어 항상 업로드합니다.
- 플래시 버튼은 지원하는 기기(주로 안드로이드)에서만 보입니다.
- 업로드가 끝난 사진은 휴대폰 저장 공간을 아끼려고 원본을 지우고 작은 미리보기만 남깁니다. 원본은 드라이브에 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html`, `styles.css` | 화면 (연결, 홈·폴더·업로드·설정 탭, 카메라) |
| `config.js` | 클라이언트 ID, 최상위 폴더 이름, 허용 도메인 |
| `js/drive.js` | 구글 로그인, 기관 계정 확인, 드라이브 폴더 생성·업로드 |
| `js/uploader.js` | 업로드 대기열 (오프라인 보관, 재시도) |
| `js/camera.js` | 앱 안 카메라 |
| `js/store.js` | 휴대폰 저장소 (IndexedDB, localStorage) |
| `js/app.js` | 화면 동작 |
| `sw.js`, `manifest.webmanifest`, `icons/` | 홈 화면 설치, 오프라인 실행 |
| `tools/serve.js` | 개발용 서버 |
| `tools/make-icons.js` | PNG 아이콘 생성 |
